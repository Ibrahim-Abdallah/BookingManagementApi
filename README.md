# Booking Management API

An ASP.NET Core REST API portfolio project focused on scheduling, availability, concurrency-safe booking, and reservation lifecycle management. Phase 01 establishes the persistence model and technical foundation without implementing later business workflows.

## Technology

.NET 10, ASP.NET Core 10, Entity Framework Core 10, SQL Server, built-in OpenAPI, Scalar, and xUnit.

## Status

Phase 01 — Foundation. See [PROJECT_PLAN.md](PROJECT_PLAN.md) for the complete phased roadmap.
